# 工业设计师作品集网页（首版骨架）

## 页面目录结构

- `index.html`：单页作品集（首页、项目列表、案例模板、关于、联系）
- `styles.css`：响应式样式与基础设计系统（色彩、排版、间距、组件）
- `script.js`：移动端菜单与项目筛选交互

## 文案模板（可直接替换）

### 首页 Hero

- 标题：`用________，把________转化为________`
- 副文案：`我专注________，擅长从________到________，推动________。`
- 主按钮：`查看精选项目`
- 次按钮：`获取完整PDF作品集`

### 项目卡片

- 项目名：`________`
- 一句话价值：`通过________，将________提升/降低________%`
- 分类标签：`消费电子 / 家具 / 可持续 / 医疗 / 智能硬件`

### 项目详情（Case Study）

1. 项目背景：
   - `目标用户是谁、核心使用场景是什么、业务目标是什么。`
2. 研究洞察：
   - `访谈/观察了多少人，提炼了哪些关键痛点。`
3. 设计过程：
   - `草图数量、关键设计决策、原型验证方法。`
4. 结果与影响：
   - `量化结果（成本、效率、满意度、转化、奖项、量产状态）。`

## 使用方式

1. 本地预览
   ```bash
   python3 -m http.server 4173
   ```
2. 访问 `http://localhost:4173`
3. 替换项目内容与联系方式后即可部署到 Vercel / Netlify。
